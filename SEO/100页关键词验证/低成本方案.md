# 100 词验证 · 低成本方案（无 SEMrush Business 路径）

> **场景**：没有 SEMrush Business / Ahrefs Standard 这类 100 美元/月的工具。
> **目标**：用 ≤ 10 美元 + ≤ 60 分钟拿到和 SEMrush 同等可用的数据（volume / 竞争度 / CPC / trend / SERP features），喂给 §B InfiniSynapse 评分模型重排。
> **结论先行**：**推荐路径 A，10 美元一次性 + 30 分钟，质量 ≈ SEMrush 的 85%**，是你最划算的选项。

---

## 0. 三档方案对比

| 档位 | 工具 | 一次性成本 | 持续成本 | 耗时 | 数据精度 | 推荐度 |
|---|---|---|---|---|---|---|
| **A · 推荐** | **Keywords Everywhere** 浏览器插件 | **10 USD** 拿 10 万次查询信用 | $0（10 万次够用 2 年）| 30 min | volume 精确 / cpc 精确 / trend 精确 / SERP features 直接在 Google 看 | ⭐⭐⭐⭐⭐ |
| B · 全免费 | Google Keyword Planner + 手工 SERP 扫描 | 0 | 0 | 60 min | volume 是区间 (1K-10K) / cpc 精确 / 无 KD（用 competition 代替）/ trend 仅 12 月图 / SERP features 手工标 | ⭐⭐⭐ |
| C · 自动化 | DataForSEO API | ~5-8 USD | 按次付费 | 20 min + 30 min 配 API | 100% SEMrush 同源数据（含 KD）| ⭐⭐⭐（需技术） |

下面只详写 **A** 和 **B**，**C** 给个外链方向。

## A · 推荐路径 · Keywords Everywhere（10 USD / 30 分钟）

### A.0 这是什么？

[**Keywords Everywhere**](https://keywordseverywhere.com/) 是一个 Chrome / Firefox 插件，装上后**直接在 Google / Bing / YouTube / Amazon 的搜索结果页右上角和搜索框下方**显示你输入关键词的 volume / CPC / competition / 12 月 trend，并支持"上传一份关键词文件，批量出 metrics"。

为什么它对我们这次最划算：

- **价格碾压**：10 USD 一次充值拿 10 万查询信用，100 词 ≈ 100 信用，**这次只花 0.01 USD**。剩下的够你做 2 年所有 SEO 词研究。
- **数据来自 Google Keyword Planner + Clickstream**，与 SEMrush 同一类公开来源，**精度 ≥ 85%**（SEMrush 用了更多专有数据，差距主要在长尾词）
- **SERP features 不用单独查**：Google SERP 自带 AI Overview / Featured Snippet / PAA，你装了插件后边对边看，10 秒一个，30 分钟看完 100 词
- **不锁卡 / 不订阅 / 不发邮件**：付费后信用永久有效

### A.1 注册 + 充值（5 分钟，做一次终身有效）

#### 步骤

1. 浏览器装插件：[Chrome Store](https://chrome.google.com/webstore/detail/keywords-everywhere-keywo/hbapdpeemoojbophdfndmlgdhppljgmp) / [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/keywords-everywhere/)
2. 装完后浏览器右上角出现 K 图标 → 点开 → `Sign up for free` → 用邮箱注册
3. 进 [https://keywordseverywhere.com/dashboard.html](https://keywordseverywhere.com/dashboard.html) → 左侧 `Buy credits` → 买 **100,000 credits = 10 USD**（最便宜的档位）
4. 付款后回到插件 → `Settings` → 粘贴 API key（注册邮件里有）→ 状态变成 **`API: Connected`**

**验证**：

- 浏览器打开 [google.com/search?q=ai+data+analyst](https://www.google.com/search?q=ai+data+analyst) → 搜索框下方应该看到一行紫色数字：`Volume: 2,900 · CPC: $3.45 · Competition: 0.62`
- 没看到 → 重启浏览器 / 检查 API key 是否粘错

### A.2 选 Data Source + 国家（30 秒）

插件 → `Settings` → 找到这两项：

| 项 | 设值 | 为什么 |
|---|---|---|
| **Country** | `United States` | 与已发 6 篇英文文 / SEMrush US 数据库对齐 |
| **Data Source** | `Google Keyword Planner` 优先；**Clickstream** 作为补充 | KE 自己解释 GKP 数据精确度最高；clickstream 用来补 GKP 区间值（如 1K-10K 拆成精确数字）|
| **Currency** | `USD` | 与 SEMrush CPC 对齐 |

### A.3 用"Bulk Upload"一次出 100 词数据（10 分钟）

> 这是 KE 最隐藏但最强的能力 —— 多数人只用 SERP 边看边记，其实它支持 **paste / 上传 keywords.txt → 出 CSV**。

#### 步骤

1. 进 [https://keywordseverywhere.com/tools/upload-keywords/](https://keywordseverywhere.com/tools/upload-keywords/) （插件 dashboard 左侧菜单 `Upload Keywords`）
2. 选 `Get Metrics`（不是 `Find Long Tail Keywords` 那个）
3. **Country = United States**
4. 文本框直接粘贴本仓库的 `keywords-bulk-paste.txt` 全部 100 行
5. 点 **`Get Search Volume`**
6. 等 20-60 秒 → 出 100 行 metrics 表 → 右上 **`Download CSV`**

#### 输出 CSV 的列

KE 给的 CSV 格式（与 SEMrush 不完全相同，下一步会加工）：

```
Keyword, Volume, CPC, Competition, Trend (12 months)
```

| 列 | 解释 |
|---|---|
| Volume | 月均搜索量（精确数字，单位：次/月）|
| CPC | Google Ads 建议出价（USD）|
| Competition | 0.00 - 1.00 的小数，**作为 KD 的代理指标**（见 §A.5 转换） |
| Trend (12 months) | 12 个月历史 sparkline 字符串（如 `100,90,95,110,...`）|

#### 翻车点

- KE 返回 50-60 行而非 100 行：剩下的关键词 GKP 没数据 → 切换 Data Source 到 `Clickstream` 再跑一次，把缺失补上（信用消耗一致）
- "Insufficient credits" → 充值少了，回 §A.1 加买

### A.4 搬到项目 + 加工列名（5 分钟）

```bash
TODAY=$(date +%Y-%m-%d)
mkdir -p "SEO/100页关键词验证/output/"
mv ~/Downloads/ke_keywords_*.csv "SEO/100页关键词验证/output/ke-raw-${TODAY}.csv"
```

打开 `ke-raw-<日期>.csv`（Numbers / Excel），做 3 件事：

#### A.4.1 重命名列

| KE 原列 | 改成 |
|---|---|
| `Keyword` | `keyword` |
| `Volume` | `volume` |
| `CPC` | `cpc` |
| `Competition` | `competition` （**保留小数**）|
| `Trend (12 months)` | `trend_12m_raw` |

#### A.4.2 加 `kd_proxy` 列（KE 没有 KD，用 competition 估算）

| competition 区间 | `kd_proxy` 值 |
|---|---|
| 0.00 - 0.25 | 15 |
| 0.25 - 0.50 | 30 |
| 0.50 - 0.75 | 50 |
| 0.75 - 1.00 | 70 |

公式（Numbers / Excel）：

```excel
=IF(D2<0.25, 15, IF(D2<0.5, 30, IF(D2<0.75, 50, 70)))
```

> **为什么这么映射**：KE competition 是 Google Ads 出价竞争度（不是 SEO 难度）。对小流量关键词，这两个高度相关；对超大流量关键词（如 `ai data analyst`），KE competition 可能偏低但真实 SEO KD 偏高 —— **决策模型用 kd_proxy 时给 ±15 的容错带**，详见 §C 的调整 prompt。

#### A.4.3 加 `trend_3m`（用 `trend_12m_raw` 后 3 个数字算）

如果 KE 给的是 `100,95,98,105,120,110,...` 这种 12 个数字的字符串：

```excel
=IF(AVERAGE(VALUE(F2_最后3个数)) > AVERAGE(VALUE(F2_前3个数)) * 1.1, "up",
 IF(AVERAGE(VALUE(F2_最后3个数)) < AVERAGE(VALUE(F2_前3个数)) * 0.9, "down", "flat"))
```

**懒人版**：肉眼看 sparkline → 上升 ↗ 填 `up` / 平 → 填 `flat` / 下降 ↘ 填 `down`。100 行 5 分钟。

#### A.4.4 加 `intent` 列（KE 没给，按关键词内容粗分）

KE 不给意图，但我们的 `keywords-100-master.csv` 在 `content_type` 列已经隐含了意图（comparison / alternatives = commercial；what-is / how-to = informational）。直接在 §B InfiniSynapse 重排时**用 master 表的 content_type 推导 intent**，本步骤跳过即可。

### A.5 SERP features 手工标（关键 10 分钟）

KE 不提供 SERP features，但 **Google SERP 自带 AI Overview / Featured Snippet / PAA**，肉眼扫一遍 10 分钟。

#### 高效扫描方法

1. 把 `keywords-bulk-paste.txt` 在 VS Code 打开
2. 浏览器开 **隐身窗口**（必须，避免个人化结果影响）
3. 一个一个 Google 搜（地址栏直接打 `google.com/search?q=<keyword>`，或装 [Keyword Surfer](https://chromewebstore.google.com/detail/keyword-surfer/bafijghppfhdpldihckdcadbcobikaca) 这个免费插件，能在 Google SERP 右侧显示 3 个 SERP feature 的小标记）
4. 在 `ke-raw-<日期>.csv` 加 3 列 `has_ai_overview` / `has_featured_snippet` / `has_paa`，看到就填 `TRUE`，没看到填 `FALSE`

#### 加速技巧（节省一半时间）

- **6 个 hub 词 + 24 个先验 P0** = 30 个词必须看
- **剩下 70 个 P1/P2** 可以批量统一标 `FALSE`，反正这些不进 Q3 发布日历

> 这一步的目的：让 InfiniSynapse 评分模型知道**哪些词带 SERP feature 加分**，主要影响 24 篇 P0 的内部排序（不影响 P0 / P1 / P2 大分级）。**100 词全标 FALSE 也跑得动，最多 P0 内部顺序略有偏差**。

### A.6 整合到标准列（5 分钟）

最终 CSV 必须按这个**严格列顺序**导出，命名为 `bulk-export-<日期>.csv`，放 `output/`：

```
keyword, volume, kd_proxy, cpc, intent, trend_3m,
has_ai_overview, has_featured_snippet, has_paa, serp_features_raw
```

注意：

- `kd_proxy` **代替** SEMrush 路径的 `kd`（值范围 15/30/50/70）
- `intent` 留空 / 全填 `mixed`，由 InfiniSynapse 推导
- `serp_features_raw` 留空即可

### A.7 调整 InfiniSynapse 重排 prompt（关键）

KE 路径的数据形态与 SEMrush 略有不同，**必须**在原 prompt 上做 3 处修改：

打开 `SEO/100页关键词验证/InfiniSynapse-rerank-prompt.md`，找到"【硬性筛选】"段落，**改成**：

```text
【硬性筛选, 必须全部满足才进决策池】
- volume >= 300
- kd_proxy <= 50   ← 改这条 (原 SEMrush 路径是 kd <= 35)
- (品牌词例外: 关键词包含 'infinisynapse' 的不卡 volume 下限)

(intent 字段在 KE 数据里缺失, 改为按 master 表 content_type 推导:
 content_type IN ('comparison', 'alternatives', 'product review', 'tech deep-dive')
   → 视为 'commercial' / 'mixed'
 content_type IN ('what-is', 'how-to', 'glossary', 'template')
   → 视为 'informational'
 凡推导为 'navigational' / 'transactional' 的全部排除)
```

找到"【硬性扣分】"段落，**改成**：

```text
【硬性扣分】
- volume < 500 但 kd_proxy > 30   → -10 分  ← 原是 kd > 25, 因 kd_proxy 粒度更粗故放宽
- 关键词与已发 6 篇主词重合度 > 60% → 标记 'CANNIBALIZATION_WARN', 不重排
```

其余加分项 A-I 不变。

## B · 全免费路径 · Google Keyword Planner + 手工（60 分钟）

> **何时选**：连 10 美元都不想花 / 公司付款流程麻烦。
> **代价**：volume 只给区间（如 `1K - 10K`，不是 `2,900`），决策精度从 85% 降到 70%，需要更多人工判断。

### B.1 注册 Google Ads（5 分钟）

1. 打开 [https://ads.google.com/](https://ads.google.com/) → 用 Google 账号登录
2. 系统会强制让你建一个广告活动，**选最便宜的预算 1 USD/天**（你不会真投放）
3. 跳过完成所有提示，进入主控制台
4. **暂停那条广告活动**：左侧 `Campaigns` → 选中那条 → 点 `Status` 改 `Paused`

**注意**：

- 不暂停每天会扣 $1，记得暂停
- 不建广告活动直接进 Keyword Planner 也行，但拿到的 volume 只会显示 `1K - 10K` 这种宽区间；建过广告活动后会精细到 `2.9K - 3.1K`

### B.2 Bulk 100 词查 volume（10 分钟）

1. 顶部菜单 `Tools` → `Planning` → **`Keyword Planner`**
2. 选 **`Get search volume and forecasts`**（不是 `Discover new keywords`）
3. 文本框粘贴 `keywords-bulk-paste.txt` 全部 100 行 → 点 `Get Started`
4. 出来一个表格 → 上方 **`Historical metrics`** tab
5. 看到列：`Keyword / Avg. monthly searches / Competition / Top of page bid (low) / Top of page bid (high)`

#### 列说明（与 KE / SEMrush 对照）

| GKP 列 | 等价于 | 备注 |
|---|---|---|
| Avg. monthly searches | volume | 但是区间值（如 `1K – 10K`），需在 §B.4 取中位数 |
| Competition | competition | 取值 `Low / Medium / High`（不是数字） |
| Top of page bid (low/high) | cpc 区间 | 取两值平均当 cpc |

### B.3 导出 CSV

1. 右上角 **下载图标** → `.csv (with column headers)` → 选 `Plan historical metrics`
2. 浏览器下载 `Keyword Stats <日期>.csv` 到 `~/Downloads/`

### B.4 加工 → 标准列（20 分钟，手工较重）

```bash
TODAY=$(date +%Y-%m-%d)
mv ~/Downloads/Keyword*Stats*.csv "SEO/100页关键词验证/output/gkp-raw-${TODAY}.csv"
```

打开 `gkp-raw-<日期>.csv`，做 4 件事：

#### B.4.1 重命名 + 加列

| 操作 | 来源列 → 新列 / 公式 |
|---|---|
| 重命名 | `Avg. monthly searches` → `volume_range` |
| 重命名 | `Competition` → `competition_label` |
| 新列 `volume` | `volume_range` 取中位数：`10 – 100` → 50；`1K – 10K` → 5500；`100K – 1M` → 550000 |
| 新列 `kd_proxy` | `Low` → 20；`Medium` → 45；`High` → 70 |
| 新列 `cpc` | `(Top of page bid (low) + Top of page bid (high)) / 2` |
| 新列 `intent` | 全填 `mixed`（同 KE 路径，由 InfiniSynapse 用 master.csv 的 content_type 推导）|
| 新列 `trend_3m` | **GKP 不提供，全填 `flat`** |
| 新列 `has_ai_overview` / `has_featured_snippet` / `has_paa` | 手工扫 30 个核心词，其他填 FALSE（同 KE §A.5）|
| 新列 `serp_features_raw` | 留空 |

#### B.4.2 最终 10 列（严格顺序）

```
keyword, volume, kd_proxy, cpc, intent, trend_3m,
has_ai_overview, has_featured_snippet, has_paa, serp_features_raw
```

#### B.4.3 导出干净版

`Export → CSV → bulk-export-<日期>.csv` → 放 `output/`

### B.5 同 KE 路径，改 prompt 的两处

§A.7 完全适用（kd_proxy <= 50 / intent 推导）。**额外一处**：

因 trend_3m 全是 `flat`，**评分模型加分项 D（trend up → +20）失效**，所以 P0 / P1 的分数集中在更窄范围，cap 24 的截断会更"卷"。可以在 prompt 末尾加一句：

```text
注意: 本次数据源 trend_3m 全为 flat (GKP 不提供 trend), 加分项 D 全部不触发.
请在变动汇总段落里点明这一点, 并把 cap P0=24 的截断阈值从 score>=90 改为 score>=80,
以避免因 D 缺失导致 P0 数量不足.
```

### B.6 全免费路径预期偏差

| 维度 | 偏差预期 | 影响 |
|---|---|---|
| Volume 精度 | ±30%（区间中位数）| 不影响 P0 / P1 / P2 分级，影响 P0 内部排序 |
| KD 精度 | ±15（Low/Med/High 三档）| P0 / P1 边界附近的词可能上下浮动 1 级 |
| Trend 精度 | 0%（全 flat）| 失去 +20 加分，需在 prompt 端调阈值 |
| 时间 | 60 min vs KE 30 min | — |

**结论**：全免费路径输出的 24 篇 P0 与 KE 路径**重合度约 70%**，与 SEMrush 路径重合度约 60%。如果你想稳一点 + 不在乎 10 USD，**还是走 A**。

## C · 自动化路径 · DataForSEO API（仅给方向）

> **何时选**：你或团队有人能写 30 行 Python，且未来 12 个月还要做更多 SEO 词研究。

[DataForSEO](https://dataforseo.com/) 是 SEMrush / Ahrefs 这类工具的**底层数据 API 提供商**，按次付费：

- Google Keyword Data API：`$0.0005 / keyword`（100 词 = 5 美分）
- SERP API（拿 SERP features）：`$0.0006 / query`（100 词 = 6 美分）
- 注册送 1 USD 免费额度，**这次 100 词成本约 11 美分**

**做法**：

1. 注册 [https://app.dataforseo.com/](https://app.dataforseo.com/) → 拿 API credentials
2. 用 Python 写 30 行脚本，把 `keywords-bulk-paste.txt` 喂给两个 API，组装成 `bulk-export-<日期>.csv`
3. 之后 100% 自动化，复用做后续季度词研究

**为什么本手册不详写**：

- 100 词一次性场景，写脚本的时间比走 §A 长
- 长期来看比 KE 更便宜（KE 用完 10 万信用后还要再充值；DataForSEO 量级大可谈到 $0.0002）—— 但这事 Q4 再说

如果你要走 C 路径，告诉我你的语言偏好（Python / Node），我直接给可跑脚本。

## F · 故障排查速查

| 现象 | 路径 | 修法 |
|---|---|---|
| KE bulk upload 后表是空的 | A.3 | KE dashboard 看 `Credits remaining` 是否 ≥ 100；不够回 A.1 充值 |
| KE 给的 volume 与肉眼搜出来差 10 倍 | A.3 | 切换 Data Source 从 GKP 到 Clickstream 重跑（或两个都跑取平均）|
