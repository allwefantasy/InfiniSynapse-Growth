### A.7 列加工（关键 5 分钟，影响决策准确度）

> SEMrush 原始 CSV 的列名与我们 prompt 要求的列名不一致，必须加工一次。**用 Numbers / Excel 都可以，不用写代码**。

**用 Numbers 打开**：

```bash
open "SEO/100页关键词验证/output/bulk-export-raw-2026-06-05.csv"
```

**做 4 件事**：

#### A.7.1 重命名列

| SEMrush 原列名 | 改成 |
|---|---|
| `Keyword` | `keyword` |
| `Search Volume` 或 `Volume` | `volume` |
| `Keyword Difficulty` 或 `KD%` | `kd` |
| `CPC (USD)` | `cpc` |
| `Intent` | `intent` |
| `SERP Features` | `serp_features_raw` |

#### A.7.2 加 `trend_3m` 列

如果 SEMrush 给的 Trend 是一个 sparkline 字符串（不是分月数字），**肉眼 100 行手工标**：

- 看小图最右侧 3 个点的斜率：**↗ 上升 / → 平 / ↘ 下降**
- 在 `trend_3m` 列填 `up` / `flat` / `down`

100 行肉眼过，约 5 分钟。**不用追求 100% 准确**，决策模型在 ±20% 误差内仍稳健。

> **省力版**：如果懒得标，全填 `flat` —— 这次发布日历不会因为 trend 误差出大错，最多 P0 名单 ±2 篇浮动。

#### A.7.3 加 3 列 SERP 布尔

在最右侧加 3 列，用公式（Numbers 里 `IFERROR(SEARCH(...), 0)` 或 Excel 同款）：

| 新列 | 公式（假设 `serp_features_raw` 在 F 列）|
|---|---|
| `has_ai_overview` | `=IF(ISNUMBER(SEARCH("AI Overview", F2)), TRUE, FALSE)` |
| `has_featured_snippet` | `=IF(ISNUMBER(SEARCH("Featured Snippet", F2)), TRUE, FALSE)` |
| `has_paa` | `=IF(ISNUMBER(SEARCH("People Also Ask", F2)), TRUE, FALSE)` |

下拉填充到 100 行。

#### A.7.4 最终列顺序（严格）

把列拖拽到这个顺序：

```
keyword, volume, kd, cpc, intent, trend_3m, has_ai_overview,
has_featured_snippet, has_paa, serp_features_raw
```

#### A.7.5 导出干净版

`File → Export To → CSV...` → 命名 `bulk-export-2026-06-05.csv`（**去掉 `-raw`**）→ 保存到 `SEO/100页关键词验证/output/`

**验证**：

```bash
head -3 "SEO/100页关键词验证/output/bulk-export-2026-06-05.csv"
# 预期第 1 行就是上面 10 个列名
wc -l "SEO/100页关键词验证/output/bulk-export-2026-06-05.csv"
# 预期 71-101 行（含 header）—— 看 SEMrush 给了多少有效数据
```
