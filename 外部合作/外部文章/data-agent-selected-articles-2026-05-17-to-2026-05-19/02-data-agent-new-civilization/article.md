# Data Agent 是驶向新文明的第一艘飞船

人类已经彻底进入了一个新文明，对，我说的是文明而不是其他。

当我们每个人都怕落后而不断聚焦在 LLM 的使用上，探索其可能，但是很少有人考虑到事情的延续性。

Code Agent 落地之后，他带来了什么价值？我的看法是：他并没有带来直接的财富，他甚至让人类消耗了更多的财富，但这是一项构建新文明下新工具的基础。

如果说 Code Agent 是人类驶向新文明的第一步，那么他类似星际文明里的某个文明终于可以时空穿梭、实现星际旅行的飞船构建技术。有了这个构建技术，我们要开始构建飞船了。

而第一艘飞船就是 Data Agent。

一旦我们将飞船构建好，将极大彻底实现未来的数据驱动、数据自动化决策，为 AI 未来做决策提供依据。

对的，AI 也不能像人类通过拍脑袋做决策，而要源于数据。

首先给人类提供快速决策依据是第一步，第二步便是给 AI 自己提供决策依据。
