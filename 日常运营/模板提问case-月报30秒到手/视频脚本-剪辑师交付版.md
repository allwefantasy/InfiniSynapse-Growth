# 视频剪辑脚本 · InfiniSynapse 表单提示词模板

**目标时长**：38 秒（30–40s 区间，X / 视频号 / 抖音通投甜区）
**风格定位**：硅谷产品片——Linear / Vercel / Stripe / Notion / Arc Browser
**核心叙事**：**上个月手搓 4 小时月报，这个月填一个日期 30 秒到手**
**功能主推**：表单提示词模板（公众号原文配套：[告别重复输入！表单+AI 让数据分析效率翻倍](https://mp.weixin.qq.com/s/Njib8r1fksJutzybvrz6cw)）

## 一、录制前准备清单（运营 + 视频同学协同 · 录制前 24h 完成）

### A. 数据源就位（运营负责）

在 `/database/private` 提前接入并启用 1 个含真实业务体感的源（推荐选项，按已有资产二选一）：

| 选项 | 数据源名建议 | 内容要点 |
|---|---|---|
| **首选** | `linxi_shopify_2026`（沿用电商月报 case 已有的 Shopify 资产） | 含 5–6 个月订单明细：order_id / user_id / sku / amount / order_time / city / channel |
| **备选** | `infinisynapse_metrics_2026` | 公司自营产品指标表：date / pv / signup / activate / paid / churn |

✅ **录制前必跑一次基线提问**确认数据可用：直接在普通输入框问 `用 <数据源名> 出 2026 年 5 月的销售月报概览` ，能跑出图表 + 结论即合格。

### B. 模板就位（运营负责，**这一步是录制成功的关键**）

进入 `/`（首页）右上侧栏齿轮 → **高级设置 / 模板管理** → **新建模板**：

| 字段 | 填写内容 |
|---|---|
| **模板名称** | `月度运营月报`（中文 9 字内，确保侧边栏不截断） |
| **模板说明**（可选） | `选一个月份，自动生成完整运营月报：GMV、复购、渠道 ROI、异常归因` |
| **模板正文** | 见下方代码块（**约 600 字，刻意写"长"以制造视觉冲击**） |
| **变量** | 仅 1 个：`month`，类型 = **日期**，格式 = `YYYY-MM`（精确到月） |

**模板正文（直接复制进模板管理器）**：

```text
你是 D2C 品牌「林夕家居」的数据运营 Copilot。请基于已接入的 linxi_shopify_2026
数据源，为我生成 {{month}} 的完整月度运营月报，需要严格包含以下 5 个模块，
每个模块都给一张图表 + 一段不超过 80 字的洞察：

1. GMV 概览
   - 当月 GMV 总额、环比上月涨跌幅、同比去年涨跌幅
   - 按周拆分趋势图（柱状图）
   - 洞察重点:是否打破历史峰值,异动周次的可能原因

2. 渠道 ROI 排名
   - 按 channel 维度汇总 GMV / 订单数 / 客单价
   - 渠道贡献占比饼图 + 横向柱状对比图
   - 洞察重点:Top1 渠道是否健康,是否过度依赖单一渠道

3. 复购率分析
   - 整体复购率(同一 user_id 在当月下单 >= 2 次的占比)
   - 分城市复购 Top 5 + Bottom 5(柱状图)
   - 洞察重点:复购洼地城市是否需要专项运营

4. 异常订单归因
   - 当月异常订单数(退款 / 取消 / 物流投诉)
   - 按 sku / city 双维度热力图
   - 洞察重点:是否存在集中爆发的 SKU 或区域,给出 next-step 建议

5. 月度结论 + 下月行动项
   - 用一句话总结当月最关键的 1 个机会、1 个风险
   - 给运营团队 3 条可执行的下月行动项,按 ROI 倒序

所有数字必须从 SQL 实算得出,禁止编造。所有结论必须标注证据(来自哪张表 / 哪段查询)。
```

> ⚠️ 模板正文里**只有 `{{month}}` 一个变量**。这是本视频的视觉灵魂——**填一个空，跑出 5 块完整内容**。变量再多就稀释震撼感。

### C. 提前跑 1 次"练习场"任务（视频同学负责）

录制前 12h 内，用同一模板填入 `2026-05` 真跑一次，记录：

| 数据点 | 用途 |
|---|---|
| 实际任务时长（从点发送到 Task completed 的秒数） | 决定字幕 [04] 段的停留节奏 |
| 实际跑出来的 phase 数量（5–7 个） | 决定字幕切换次数 |
| `taskId` UUID | 万一录制翻车，可用此任务结果素材补救 |
| 最终报告滚动到底的总长度（px） | 决定 [05] 段滚动滚屏的速度参数 |

✅ **录制开始前再跑一次**（用 `2026-04` 而非 `2026-05`，避免缓存看起来太"假"）——这次是正式录屏。

### D. 录屏环境（视频同学负责）

| 项 | 值 | 说明 |
|---|---|---|
| 工具 | `agent-browser daemon`（按 `Skills/infinisynapse-app-skill/SKILL.md` §0–§1） | 自动化稳，无鼠标抖动 |
| 视口 | **1440 × 900** | 横版录屏标准 |
| 终版尺寸 | **1080 × 1920**（竖版优先）+ **1920 × 1080**（横版备份） | 竖版铺 X / 视频号 / 抖音；横版铺 LinkedIn / YouTube / 官网 |
| 帧率 | 30fps | 屏幕录制甜区 |
| 录屏软件 | OBS Studio 或 macOS 自带屏幕录制 | OBS 优先（自带 timer 叠加） |
| 计时器 | **OBS 内置 Timer Source**，左上角固定显示 `00:00`，字号 48px，半透明黑底白字 | **本视频的视觉锚点**，全程必显 |
| BGM | 1 段 Lofi / Ambient，-18 dB，全程不切歌 | 推荐 `Epidemic Sound · Productive Mornings` 或同类 |
| 鼠标 | 启用 OBS 的"光标高亮"特效（黄圈半透明 40% 不透明度） | 让观众看清点击位置 |
| 网络 | 录前 5 分钟 ping `app.infinisynapse.com` 确认无丢包 | Agent 跑动期间网络抖动会拉长时长 |

### E. agent-browser 录屏命令链路（视频同学按 SKILL.md 复制粘贴）

完整命令链路放在 `录制命令-逐步执行.sh` 里（详见末尾"附录 A"），关键节点：

1. §1 登录态预检
2. §4.0 + §4.1 在首页输入框区域**点"模板提问"按钮**（不是直接 fill 文本）
3. 等模板表单弹窗 → JS 选中模板 `月度运营月报`
4. JS 填日期字段为 `2026-04` → JS 点发送
5. §7.1.0 综合信号轮询 → 等 `任务完成` 出现
6. §7.2 双 `.overflow-auto` 容器 → 滚动 `[1]` 展示最终报告

### [02] 进入产品 · 点"模板提问" · 0:03 – 0:08

| 项 | 内容 |
|---|---|
| 源素材 | R-1 · 进入 `/tasks` 首屏 → 鼠标移到输入框右侧 → 点击「**模板提问**」按钮 |
| 画面目的 | **3 件事必须看清**：① InfiniSynapse 主界面（建立产品认知）② 输入框旁边那个**「模板提问」按钮**（功能入口的视觉记忆点）③ 弹出的表单只有 **1 个日期选择器**（信息量极少 → 反差感 ） |
| 持久角标 | **左上角始终显示 OBS 计时器**：`00:00`（这一段计时器**还未启动**，停在 0:00 静止状态，配合字幕"watch this"暗示观众"马上要计时了"） |
| 关键操作高亮 | 当鼠标点到「模板提问」按钮时，剪辑师**加一个 0.4 秒的黄色光圈环动效**（OBS 录屏自带光标高亮即可，无需后期） |

| 配音（共用） | `Open InfiniSynapse. Click "Template Question". A form pops up.` |
| 速度 | **原速** —— 这一段是建立信任的"展示真实交互"段，**绝对不能加速** |

### [03] 填 1 个日期 · 启动计时 · 0:08 – 0:12 ⭐ 视觉锚点

| 项 | 内容 |
|---|---|
| 源素材 | R-1 · 表单弹窗展开 → 鼠标点日期选择器 → 选 `2026-04` → 点发送按钮 |
| 画面目的 | **核心镜头**——观众必须清晰看到"**这个表单只有 1 个字段**"。整段 4 秒不能切镜，全程一镜到底。 |
| 持久角标 | **OBS 计时器在「发送按钮被点击的瞬间」启动**（从 `00:00` 开始走秒）——剪辑师需要**精确对齐这一帧**，时间码大约在 0:11 处 |
| 模板正文露脸 | 选完日期后、点发送前，可让鼠标短暂滑过"标准提问"切换按钮 1 帧（**约 0.3s**），让观众瞄到背后那段 600 字的 prompt 全文被自动展开——视觉上**"少 → 多"的瞬间扩张**是本段的暗藏冲击点 |
| 英文字幕（两版共用） | **Fill 1 field. Hit send.** |
| 中文字幕（仅 ZH 版叠加） | 填 1 个字段，按下发送 |
| 配音（共用） | `One field. Pick the month. Hit send.` |
| 速度 | **原速** |

### [04] Agent 跑动 · 计时器走秒 · 0:12 – 0:28 ⭐⭐ 速度感担当

| 项 | 内容 |
|---|---|
| 源素材 | R-1 · Agent 跑 5–7 个 phase 全程 |
| 画面目的 | **三件事并行展示**：① **OBS 计时器持续走秒**（左上角，始终在场）② **侧边对话区涌现 `.compact-tool-row` 工具行**（暗示 Agent 正在调度 SQL / RAG / 绘图） ③ **进度数字 `2/5 → 3/5 → 4/5 → 5/5` 在底部状态条更新**（数字感 = 进度感） |
| **加速处理** | **整段 4× 倍速**（如果实际任务跑了 90s，剪辑后压到 ~16s）—— **但计时器不加速、按原始 1× 真实时间走**。这就是本视频最大的"魔法"：观众看到 Agent 飞速跑了 5 个阶段，左上角计时器只爬到了 0:28。**视觉上的速度差 = 产品力的具象化**。 |
| 工具行特写 | 在加速过程中**插 2 个 1 秒的全速镜头**作为节奏锚点：①  `.compact-tool-row` 第一次被渲染出（约 0:14）②  `.compact-tool-row` 内出现"绘制柱状图"这类带画面感的字（约 0:22） |
| 英文字幕切换 | 三句字幕用 §7.1.3 的"DOM 信号检测"切换，**不要硬定时**：<br>① 0:12 起：`Planning the report…`（检测信号：phase 1 出现）<br>② 0:18 起：`Running SQL across 5 dimensions`（检测信号：第一个 `pre code` 元素出现）<br>③ 0:23 起：`Drawing 4 charts`（检测信号：第一个 `svg[class*=chart]` 出现） |
| 中文字幕（仅 ZH 版叠加） | ① 规划月报结构<br>② 5 个维度并行跑 SQL<br>③ 自动绘制 4 张图表 |
| 配音（共用） | `Planning the report... running SQL across five dimensions... drawing four charts.`（配音节奏与三句字幕严格对齐） |
| 转场到 [05] | 当画面检测到 `任务完成` 信号时，**计时器最后跳一帧停在 ~0:28**，画面 0.3 秒黑闪 → 进 [05] |

## 五、声音设计

| 元素 | 处理 |
|---|---|
| **BGM** | Lofi / Ambient 单段，-18 dB，从 0:00 淡入到 0:01，0:36 起淡出到 0:38 结束 |
| **配音 VO** | 录音棚级 mono / 22050Hz / -3 dB / **干净无混响** —— 配音师参考 [Linear · 2024 Launch Week](https://linear.app/) 视频里的旁白质感（节制、不亢奋） |
| **关键音效** | 仅 3 处，全片不超过：<br>① [03] 点发送按钮 → 极轻 `tick` 音（10ms）<br>② [04] 每出一个工具行 → 极轻 `tick`（视情况，不超过 4 次）<br>③ [05] 计时器锁帧 + 染绿瞬间 → 极轻 `ping`（同 Linear 风格） |

## 附录 A · agent-browser 录屏命令链路（视频同学执行）

> 严格按顺序执行，每段都依赖 `Skills/infinisynapse-app-skill/SKILL.md` 里对应的章节。**第一次跑请打开 SKILL.md 对照**。

```bash
#!/bin/bash
# 录制 R-1 · InfiniSynapse 表单提示词模板 30 秒月报 demo
# 执行前确认: 1) 模板"月度运营月报"已建好  2) 数据源 linxi_shopify_2026 已启用
# 录屏软件 (OBS) 先开始录制再执行本脚本

AGENT=~/.auto-coder/.autocodertools/agent-browser
set -e

# ============ §1 登录态预检 ============
$AGENT daemon status || $AGENT daemon start
$AGENT set viewport 1440 900
$AGENT open "https://app.infinisynapse.com/tasks"
$AGENT wait 2500

# 校验已登录: URL 不应含 /login
URL=$($AGENT get url)
[[ "$URL" == *"/login"* ]] && { echo "未登录,请手动扫码"; exit 1; }
echo "[OK] 登录态正常: $URL"

# ============ §4 镜头预热: 鼠标移到输入框右下角"模板提问"按钮 ============
# 模板提问按钮的稳定特征: 输入框工具栏右侧最后一组按钮里, textContent 含 "模板"
$AGENT wait 1500   # 让 OBS 录屏先稳定 1.5s 录个静止的首屏

# JS 找到"模板提问"按钮并点击
$AGENT eval "(() => {
  const btn = [...document.querySelectorAll('button, [role=button]')]
    .find(b => /模板提问|Template Question/.test(b.textContent) && b.offsetParent);
  if (!btn) return 'not-found';
  // 滚动到中心 + 让鼠标视觉上"飘"过去再点 (录屏更自然)
  btn.scrollIntoView({block:'center'});
  btn.click();
  return 'clicked';
})()"
$AGENT wait 1500   # 让表单弹窗动画完整展开

# ============ 选择"月度运营月报"模板 ============
# 模板列表在弹窗内通常是 .ant-modal 内的列表项 / 卡片
$AGENT eval "(() => {
  const modals = [...document.querySelectorAll('.ant-modal')]
    .filter(m => m.offsetParent && m.getBoundingClientRect().height > 100);
  for (const m of modals) {
    const tpl = [...m.querySelectorAll('div, li, button')]
      .find(d => /^月度运营月报\$/.test(d.textContent.trim()));
    if (tpl) { tpl.click(); return 'tpl-selected'; }
  }
  return 'tpl-not-found';
})()"
$AGENT wait 1200   # 表单字段渲染

# ============ §3.3 警惕 antd 弹窗: 填日期字段 ============
# 日期选择器是 antd DatePicker, value 用 React setter 注入
$AGENT eval "(() => {
  const dp = document.querySelector('.ant-modal input.ant-picker-input, .ant-modal input[placeholder*=月]');
  if (!dp) return 'no-datepicker';
  const setter = Object.getOwnPropertyDescriptor(window.HTMLInputElement.prototype, 'value').set;
  setter.call(dp, '2026-04');
  dp.dispatchEvent(new Event('input', {bubbles: true}));
  dp.dispatchEvent(new Event('change', {bubbles: true}));
  dp.blur();
  return JSON.stringify({val: dp.value});
})()"
$AGENT wait 800

# ============ (可选) 鼠标短暂划过"标准提问"切换 tab, 让 prompt 展开 0.3s ============
# 这一帧是 [03] 段"少→多"的视觉冲击点
$AGENT eval "(() => {
  const tab = [...document.querySelectorAll('button, [role=tab], div')]
    .find(t => /^标准提问\$/.test(t.textContent.trim()) && t.offsetParent);
  if (tab) { tab.click(); return 'switched'; }
  return 'no-tab';
})()"
$AGENT wait 300   # 仅露 0.3s
# 切回模板提问 tab
$AGENT eval "(() => {
  const tab = [...document.querySelectorAll('button, [role=tab], div')]
    .find(t => /^模板提问\$/.test(t.textContent.trim()) && t.offsetParent);
  if (tab) { tab.click(); return 'back'; }
  return 'no-tab';
})()"
$AGENT wait 500

# ============ §4.1.2 点发送按钮 ============
# 模板表单弹窗内的发送按钮, 通常是底部的 primary 按钮 "发送"/"提问"/"Send"
$AGENT eval "(() => {
  const modals = [...document.querySelectorAll('.ant-modal')]
    .filter(m => m.offsetParent);
  for (const m of modals) {
    const btn = [...m.querySelectorAll('button')]
      .find(b => /发送|提问|提交|Send|Submit/.test(b.textContent) && b.offsetParent);
    if (btn) { btn.click(); return JSON.stringify({clicked: btn.textContent.trim()}); }
  }
  return 'no-send';
})()"
# !!! 这一帧是 OBS 计时器启动的对齐点 !!!
# 剪辑师需要找到这一帧 (从录屏里能看到模态框关闭 + 任务页跳转的瞬间)
$AGENT wait 4000

# ============ §7.1.0 综合信号轮询: 等任务完成 ============
for i in $(seq 1 60); do
  sleep 5
  STATE=$($AGENT eval "(() => {
    const txt = document.body.innerText;
    const tail = txt.slice(-2000);
    const done = tail.includes('任务完成') || tail.includes('Task completed');
    const m = [...txt.matchAll(/(\\d+)\\s*\\/\\s*(\\d+)/g)]
      .filter(x => parseInt(x[2])>=1 && parseInt(x[2])<=15);
    const last = m.length ? m[m.length-1] : null;
    return JSON.stringify({done, phase: last ? last[1]+'/'+last[2] : null});
  })()")
  echo \"[$i] $STATE\"
  echo \"$STATE\" | python3 -c \"
import json,sys
s=sys.stdin.read()
try:
  o=json.loads(json.loads(s))
  exit(0 if o['done'] else 1)
except: exit(1)\" && { echo '[OK] 任务完成'; break; }
done

# ============ §7.2 滚动展示: [05] 段从顶滚到底 ============
# 先滚到对话顶部 (Phase 1)
$AGENT eval \"document.querySelectorAll('.overflow-auto')[1].scrollTop = 0\"
$AGENT wait 2000

# 缓慢分段滚 (5 秒滚完)
for px in 400 800 1200 1600 2000 2400 2800 3200; do
  $AGENT eval \"document.querySelectorAll('.overflow-auto')[1].scrollTop = $px\"
  $AGENT wait 600
done

# 最终停在底部
$AGENT eval \"(() => {
  const c = document.querySelectorAll('.overflow-auto')[1];
  c.scrollTop = c.scrollHeight;
  return c.scrollTop;
})()\"
$AGENT wait 3000

# ============ 录屏可结束 ============
echo \"[DONE] 录制完成,可停止 OBS\"
echo \"任务链接: \$($AGENT get url)\"
```

> 这段脚本的所有 JS 选择器都基于 SKILL.md §4 / §7 实测沉淀。**第一次跑请打开 SKILL.md 对照各章节**，尤其是 §3.3（antd 弹窗按钮带空格）和 §4.1.2（发送按钮空 label）。
