### 一句话定位（给博主理解用）

> **不是替孩子填志愿，而是出分前先按省份 + 分数 / 位次跑一版冲稳保预演 PDF，把该核的招生简章、选科和专业组问题先列出来——数据有出处，缺什么会标出来。**

### 三句话卖点（内部对齐，对外请口语化）

1. **免登录快出报告**：H5 打开即用，输入省份、科类、分数或位次，几分钟出冲稳保分析 PDF，适合打印带给老师改。
2. **冲稳保 + 风险拆开讲**：不只堆学校名单——会拆冲刺 / 稳妥 / 保底梯度，并提示调剂、退档、选科匹配等需要核验的点。
3. **数据透明、不装确定**：优先查高考报名录取数据源；缺学校级录取线时会**明确标数据缺口**，建议对照省考试院、高校招生网，**不把不确定信息包装成确定结论**。

### 产品能做什么 / 不能做什么

| ✅ 能做 | ❌ 不能做 |
|---|---|
| 根据省份、科类、分数、位次生成冲稳保候选 | **替用户登录志愿填报系统** |
| 分析目标学校 / 专业能不能冲、风险在哪 | **提交、修改或确认志愿** |
| 给出需核验的官方来源建议 | **承诺保录取、保专业、100% 准确** |
| 上传成绩截图 / 章程等辅助 AI 分析（登录增强版） | 代替家长或老师做最终决策 |

## 三、创作方向（按场景选择）

博主**任选 1 个主方向**，选定后告知运营，便于分配 `kol_{昵称}` 链接。

### 方向 A · 学长 / 学姐估分预演（推荐 · 流量广）

**适合**：刚高考完、准大一、大二回顾高三的博主  
**叙事钩子**：「出分前我最后悔没早点做的一件事」  
**体验路径**：

1. 用**估分区间**（不必精确到个位）在 H5 跑一版冲稳保
2. 截图冲刺 / 稳妥 / 保底各 1–2 所，说清**为什么**这样排
3. 强调：出分后用**正式分 + 位次**重跑即可
4. 引导：打印 PDF 带给班主任或报考老师改

---

### 方向 B · 家长视角（推荐 · 转化高）

**适合**：家长小号、陪读妈妈 / 爸爸、家有高三生的账号  
**叙事钩子**：「不是替孩子做决定，是先帮他搭个框架」  
**体验路径**：

1. 写清焦虑点：信息太多、怕填错专业组、怕调剂到不能接受的专业
2. 展示输入估分 + 省份后得到的**待核验清单**
3. 态度：**工具是协作者，不是决策者**

---

### 方向 C · 出分前 Checklist（适合官方号联动）

**适合**：爱发清单、攻略类内容的博主  
**叙事钩子**：「6/25 出分前，这 7 件事现在做还来得及」  
**体验路径**：

1. 清单体：估分区间 → 查本省日程 → **跑冲稳保预演** → 核对选科 → 定调剂底线 → 标待核验 → 约老师
2. 其中一步嵌入「志愿一问达」截图
3. 与公众号 checklist 内容一致，不冲突

**可参考**：[`双渠道策略-微信群与红人.md` §13](双渠道策略-微信群与红人.md)

---

### 方向 D · 报考老师 / 班主任（专业向 · 需真实身份）

**适合**：年轻班主任、县级报考老师、教育类个人号  
**叙事钩子**：「出分后 48 小时，我会让学生先带这个来办公室」  
**要求**：

- 必须真实身份或明确「模拟老师视角体验」
- 强调**核验官方来源**，不夸大 AI 权威
- 可展示「报告内待核验项」截图

---

### 方向 E · 目标学校 / 专业能不能冲（搜索意图强）

**适合**：已有目标院校、纠结「冲不冲」的博主  
**叙事钩子**：「XX 大学 XX 专业，我这个位次到底敢不敢冲？」  
**体验路径**：

1. 填目标学校 + 目标专业 + 估分 / 位次
2. 展示产品对**冲刺空间、调剂风险、退档风险**的分析
3. 若有「数据缺口」提示，**如实展示**——这是信任点，不是缺点

## 五、常见问题 Q&A

**Q1：还没出分，只有估分，能发吗？**  
**可以，且推荐。** 产品定位就是出分前预演；文案写清「估分区间 / 出分后重跑」即可。

**Q2：必须提 InfiniSynapse 吗？**  
不强制。对用户说「志愿一问达」即可；若提团队，可写「InfiniSynapse 团队做的 Data Agent 应用」。

**Q3：报告里的学校 / 分数能直接当结论吗？**  
**不能。** 必须加免责声明；鼓励展示「待核验 / 数据缺口」截图，体现Responsible AI。

**Q4：能写「免费」吗？**  
可以。当前 H5 **免登录版**可免费生成方案；**不写未公布的付费功能或价格**。

**Q5：要勾选小红书商业合作吗？**  
本 Brief 默认 **非报备真实分享**；**不勾选未实际存在的品牌合作**。付费合作由运营线下签约，不在笔记中暴露云账户等信息。

**Q6：链接放哪里？**  
**正文不放外链**（防限流）。优先：评论区回复 / 私信发 `kol_{昵称}` 专属 H5；或只引导微信搜小程序。

**Q7：出分后还能发吗？**  
可以，角度改为「出分当天用正式分 + 位次重跑」；6/25 后需与运营确认是否延续稿费政策。

**Q8：抖音 / 微博怎么发？**  
整帖标准同上；若只做**评论区置顶**，走附录 C，**不放外链**，只写小程序名。
