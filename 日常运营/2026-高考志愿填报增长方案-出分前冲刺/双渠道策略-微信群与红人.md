| 2 | 查清本省日程 | 出分日、本科批起止 |
| 3 | 跑冲稳保预演 | 志愿一问达 · 省份+科类+估分 |
| 4 | 核对选科 | 专业组是否接受你的选科 |
| 5 | 定调剂底线 | 冲校被调剂能否接受 |
| 6 | 标「待核验」 | 对照省考试院/招生网 |
| 7 | 约老师+带清单 | 打印班主任核验清单 |

**第三部分 · 出分后 72h 预告**：正式分+位次重跑 · 一分一段 · 章程 · 专业组代码 · 调剂勾选

**第四部分 · 工具（克制）**：免费 · 免注册 · ~4 分钟 PDF · **老师的协作者**

**第五部分 · CTA**  
菜单「志愿一问达」· 链接 `utm_source=wechat_checklist`  
评论区：**省份 + 估分区间 + 最纠结的问题**

### 13.2 可直接粘贴的正文草稿

**① 估分区间** — 不必精确到个位，区间够宽冲稳保才有意义。  
**② 查清本省日程** — 只信省教育考试院官网。  
**③ 跑冲稳保预演 PDF** — 志愿一问达，看冲刺/保底/选科匹配。  
**④ 核对选科与专业组** — 填错组等于白考。  
**⑤ 定调剂底线** — 不能接受就从冲刺档划掉。  
**⑥ 处理待核验** — 出分前对照招生网改掉。  
**⑦ 约老师** — 带 PDF + 核验清单，15 分钟过方向性错误。

## 16. 链路 3 · 爆款评论区置顶（小红书 / 抖音 / 微博）

> **模式**：不自己刷屏评论，而是 **联系爆款帖作者**，问愿不愿意在评论区 **置顶一条广告评论**。  
> **适合**：**素人**博主（刚高考完、家长、小老师个人号）——已有高考相关爆款帖，置顶意愿高、报价低。  
> **报价**：普遍 **¥30–50**，按帖点赞量浮动；素人 **封顶 ¥100**（再高改走链路 1 整帖合作）。  
> **人力**：运营 A 红人线兼顾，或矩阵 4–5 专责；与链路 1 私信 **分号分时段**，避免同一博主两条线重复触达。

### 16.1 与链路 1 的区别

| | **链路 1 · 整帖发稿** | **链路 3 · 评论区置顶** |
|--|----------------------|-------------------------|
| 动作 | 新发 1 条笔记 | 在 **已有爆款帖** 下置顶 1 条评论 |
| 对象 | 百粉/千粉 · 愿意写新帖 | 已有爆款帖的 **帖主** |
| 稿费 | ¥100 起 + 14 日阶梯 | **¥30–100** 一口价 |
| 周期 | 写帖 + 审核 + 14 日看赞 | 谈妥 → 发评置顶 → 验收即结 |
| 适合 | 愿意创作、粉丝 100–5k | 不想写新帖、但帖还在涨赞评 |

### 16.2 选帖与找谁

**平台优先级**：小红书 > 抖音 > 微博（小红书置顶功能最常用、转化路径最短）

| 平台 | 选帖门槛（近 14 日） | 帖主画像 |
|------|----------------------|----------|
| **小红书** | 点赞 **≥500** 或 评论 **≥50** | 素人 · 非 MCN · 非机构硬广帖 |
| **抖音** | 点赞 **≥5,000** 或 评论 **≥100** | 同上 |
| **微博** | 转发 **≥200** 或 评论 **≥80** | 同上 |

**优先选**：估分焦虑、志愿讨论、出分倒计时、省份+分数类帖——评论区已在问「用什么工具」「怎么排志愿」。

**跳过**：MCN 报备号、机构卖课帖、万粉以上（通常不接 ¥100 以内）、政治/明星蹭梗帖、**已关评** 的帖。

**搜索词**：`2026高考` `估分` `志愿填报` `冲稳保` `出分` `{省份}高考`

### 16.3 报价参考（按帖当前点赞 · 私信先报区间）

| 帖点赞 | 建议报价 | 说明 |
|--------|----------|------|
| 500–2,000 | **¥30** | 小爆款，素人常接 |
| 2,000–5,000 | **¥50** | 最常见成交档 |
| 5,000–1 万 | **¥80** | 可略加价 |
| 1 万+ | **¥100** | **素人封顶**；再高不砍、改邀链路 1 发整帖 |

> 实际以博主还价为准：**先报区间，留 ¥10 议价空间**。抖音/微博可按上表 **×0.8** 试谈。

### 16.4 合作流程

```
搜爆款帖 → 私信帖主问置顶 → 报价确认 → 加 V（可选）
    → 发「置顶评论文案」+ 操作说明
    → 博主：自己发评论 → 置顶（或置顶我方指定评论）
    → 24h 内截图验收（置顶可见 + 评论在架）
    → 云账户结款（同 §4，不在私信提云账户）
    → 保留 ≥出分后 7 日；删帖/撤置顶 → 终止后续合作
```

**置顶评论要求**：

| 项 | 要求 |
|----|------|
| **内容** | 用 §16.6 模板，第一人称体验向，**≥60 字** |
| **导流** | 只写「微信搜小程序 **志愿一问达**」· **不放外链** |
| **置顶时长** | 至少 **7 天**，最好维持到帖热度自然衰减 |
| **形式** | 博主账号发评并置顶（首选）；或博主置顶我方小号评论（需小号先评） |

**H5（帖主或追问用户私信时用）**：`utm_source=pin_{昵称}` 或 `pin_xhs` / `pin_dy` / `pin_wb`

### 16.7 日 SOP（约 45 min / 人）

| 时段 | 动作 | 目标 |
|------|------|------|
| 上午 30 min | 三平台搜爆款 → 筛 10–15 帖 → 私信帖主 | 触达 10–15 |
| 下午 | 跟回复 · 议价 · 发文案 | 意向 2–4 |
| 傍晚 | 验收置顶截图 · 记入 CSV · 排款 | 成交 2–4/天 |

**去重**：同一帖主 7 天内只触达 1 次；已在 [`小红书-博主私信记录.csv`](小红书-博主私信记录.csv) 走链路 1 的，**链路 3 不再重复谈**（除非对方主动问能否只置顶）。

### 16.8 与链路 1 / 2 的衔接

| 场景 | 动作 |
|------|------|
| 帖主愿意但想发整帖 | 转链路 1 · ¥100 起 + 阶梯 |
| 帖主粉丝 100–5k、无爆款 | 直接走链路 1 私信 |
| 置顶后有人问工具 | 帖主楼中楼引导「微信搜 志愿一问达」 |
| 用户私信帖主再转来 | 邀进微信私域群（§6） |

### 16.9 止损线

| 信号 | 动作 |
|------|------|
| 触达 20 人 0 成交 | 检查话术/报价是否过高，降 ¥10 试 3 单 |
| 置顶后 48h 被撤 | 不结款；该博主拉黑 |
| 7 日 pin_* PDF **<10** | 维持触达量，优化选帖（优先评论问工具多的帖） |
| 链路 3 占用预算 **>¥2,500** | 暂停新谈，优先保链路 1 整帖 |
