增长调研报告 / Databricks Genie · 增长时间线

读这一页前 · 三个词

湖仓平台
Databricks 本身是企业数据平台（存数据、跑数据库查询、管权限）；Genie 是上面长出来的「用口语问数据」功能，不是单独一家公司。
Genie 空间
数据团队先配好表、指标说明、示例问题，业务用户再在聊天界面里问——强调「有护栏的自然语言分析」，不是裸的自然语言转数据库查询。
捆绑销售
已有 Databricks 数据库查询 客户的 Genie 不另收许可证费，只算仓库计算资源——增长靠现有客户基数，不靠从零做搜索优化。

Databricks Genie 采购对比标杆

0. 增长时间线：早期打法 → 流量爆发 → 现在

Genie 的路径和 Julius 完全不同：不是创业公司从 0 做搜索优化，而是已有湖仓客户 → 大会发布 → 捆绑现有合同 → 文档与最佳实践教育 → 客户内部扩散。下面按可查来源串时间线。

2013–2023 · 平台铺垫（Genie 之前）

Unity Catalog + 数据库查询 仓库 + Mosaic 人工智能栈

  • Databricks 先卖「统一数据 + 治理 + 数据库查询」——企业客户把表、血缘、文档放在平台里
  • 2023 前后强化 Data Intelligence Platform 叙事：模型能读平台里的元数据、血缘、历史查询
  • 关键判断：Genie 的「compound AI system（复合人工智能系统）」不是空降功能，而是吃已有数据资产——InfiniSynapse 若强调多库联邦，应对位「我们不必先把所有数据搬进 Databricks」

背景：AI/BI 发布文（compound AI 从 ETL、血缘、查询历史学习）

2024-06-12 · Data + AI Summit 发布

AI/BI 套件：Dashboards（正式可用）+ Genie（公开预览）

动作内容增长含义
产品定义Genie = 口语问数据 · Dashboards = 固定关键绩效指标看板「仪表盘答不了的，交给 Genie」——扩大平台内使用面
定价含在 Databricks 数据库查询 Pro / Serverless 客户合同内，无额外许可证对现有客户 = 零决策成本试用 → 内部扩散极快
发布渠道主题演讲 + 新闻稿 + 博客 + YouTube 回放大会单次触达数万数据从业者， earned media 放大
差异化叙事不做「又一家易错的自然语言转数据库查询」，做可学习、可反馈的对话分析和 ThoughtSpot Spotter、Hex 智能体同一话术战场

2024 下半年 · 预览期冷启动

文档 + 最佳实践 + 客户内测故事

  • 官方文档：创建与管理 Genie 空间——教数据分析师选表、写说明、放示例问题

早期打法本质：不是投 Google 广告，而是让已有客户的的数据团队能在 1–2 天内配出一个可给业务用的空间。
