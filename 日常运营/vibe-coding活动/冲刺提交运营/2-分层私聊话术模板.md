# 分层私聊话术模板

> 群公告是广播，私聊才有转化。把 80 名报名者分三类，逐个 1v1 触达。
> 原则：一次只说一件事、给具体帮助、给明确下一步、别群发感。称呼用真名/昵称。

---

## 分层方法（先建个表）

| 分层 | 判断依据 | 触达目标 |
|---|---|---|
| A. 已提交 | 后台有提交记录 | 感谢 + 请其邀请新人/晒作品 |
| B. 开工中 | 群里发过言/问过技术/领了 API Key | 问进度、扫清阻塞、逼近提交 |
| C. 没动静 | 报名后无任何动作 | 一句话唤醒 + 极低门槛引导 |

---

## C 类 · 没动静（最大金矿，优先私聊）

**开场（唤醒版）**
> Hi【名字】，我是 InfiniSynapse 大赛运营。看到你报名了 Vibe Coding 大赛，还没开始吧？想跟你说个事：50 个参与奖名额现在还没坐满，说白了现在交作品拿奖概率很高。想不想我帮你找个一个周末能做完的选题？

**如果回复「太忙/太难/不知道做啥」**
- 太忙：「理解～其实一个能跑的小应用，一个周末就够。要不我发你 10 个现成选题 + 示例代码，你挑一个照着改？」
- 太难：「不用从零写，我们有开源示例和 63 个模板场景，很多人是照着改出来的。发你一份带做录播 + 选题清单？」
- 不知道做啥：「这个最好办，发你一份《一周末能做完的 10 个选题》，选一个我陪你把方向定下来。」

**收尾（给明确下一步）**
> 我先发你选题清单和提交入口。你今天挑一个方向回我一下，我帮你看看可行性，好不？

---

## B 类 · 开工中（临门一脚）

**问进度**
> Hi【名字】，你的【作品名/方向】进展怎么样啦？离能提交还差哪一步——是功能、部署，还是 API 接入卡住了？说一声我帮你看看。

**针对常见阻塞**
- 卡 API：「把报错发我，或来今晚【20:00】答疑时段，我们实时帮你调通 Server API。」
- 卡部署：「作品要求是有公网可访问地址，Web 部署到【Vercel/服务器】都行，需要我发你部署参考吗？」
- 觉得没做完/不够好：「达标线其实不高：能跑 + 场景清楚 + 真的接了 InfiniSynapse 就行。先交一版，截止前还能继续迭代更新的。」

**逼近提交（承诺法）**
> 这样，你定个小目标——【X 号】前先交一版能跑的，后面再优化。要不要我给你排一次提交前的 1v1 review？

---

## A 类 · 已提交（放大 + 老带新）

**感谢 + 反馈**
> 【名字】，作品收到啦，感谢参赛！【真诚点评一句作品亮点】。有两件事想请你帮个忙——

**请求 1：晒作品**
> 方便的话，在群里/朋友圈晒一下你的作品和参赛过程？我们会在公众号「优秀作品展示」里帮你露出，也给还在观望的人打个样。

**请求 2：老带新**
> 如果身边有想练手的朋友，欢迎拉进来组队或单独参赛，你邀请成功可以拿【权益】。现在提交人数不多，你朋友来交基本稳拿参与奖。

---

## 通用注意事项

- 一天集中处理一类，别一次群发式轰炸。
- 每条都带一个「具体的下一步」，不要停在寒暄。
- 对方给了回应就当天跟进，别晾着。
- 把私聊里高频卡点收集起来 → 反哺群公告和答疑，形成循环。
