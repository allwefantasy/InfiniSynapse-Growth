# 10 个「一个周末就能做完」的选题清单

> 用途：发给「不知道做啥」的选手，直接降门槛。每个选题都满足大赛硬要求——可运行的 Web 应用 + 明确场景 + 通过 Server API 调 InfiniSynapse 完成分析。
> 共同技术骨架：前端一个输入框/上传框 → 后端调 `POST https://api.infinisynapse.cn/v1/query`（Bearer sk-xxxx）→ 把返回的结构化结果渲染成表格/图表。会这一条，下面 10 个都能套。

> 难度标注：🟢 一天可完成 ｜🟡 一个周末 ｜🔵 周末 + 少量打磨

---

## 电商 / 消费

1. **店铺差评体检助手** 🟢
   上传某商品的评价列表，AI 归类高频吐槽点、算负面占比、给改进建议。场景清晰、数据好造，最适合新手第一个作品。

2. **跨平台比价 & 券后到手价计算器** 🟡
   输入商品名，AI 整理各平台价格、算券后价、读差评避坑，输出一张比价表。呼应官方「省钱比价助手」，可做垂直细分（如美妆/数码）。

3. **选品趋势速览** 🟡
   上传销售/搜索数据，AI 找出增长最快和下滑最狠的品类，给下周备货建议。B 端小卖家刚需。

## 职场 / 教育

4. **入职前公司尽调助手（细分版）** 🟡
   输入公司名，分维度核验主体、融资、口碑、风险信号。可只做某一行业（如互联网大厂），比通用版更快落地。

5. **简历-JD 匹配诊断** 🟢
   上传简历 + 目标 JD，AI 打匹配分、指出缺失关键词、给修改建议。学生党高频。

6. **高考/考研志愿分数位次分析** 🔵
   输入分数、位次、意向，AI 给冲稳保参考。数据准备成本略高，但话题性强。

## 数据 / 运营

7. **SEO 数据十维体检**（已有样板）🟡
   上传 GSC 导出数据，AI 出核心指标、趋势、快速机会、诊断建议。可直接参考已上线案例，改个皮就是新作品。

8. **广告投放周报生成器** 🟡
   上传投放数据，AI 算 ROI、找异常、生成带图表的周报，一键导出。中小投手刚需。

9. **社媒评论舆情看板** 🔵
   上传一批评论/私信，AI 做情绪分类、提炼话题、标记需人工跟进的负面。

## 生活 / 决策

10. **租房/offer 决策打分器** 🟢
    输入 2-3 个候选（房源或 offer）的关键信息，AI 按你的权重打分给建议。轻量、好演示、易出彩。

---

## 挑选建议

- **求稳拿参与奖**：选 🟢（1、5、10），一天做完，功能小而完整就达标。
- **想冲高名次**：选 🟡/🔵 里场景清晰、UI 能打的（2、7、8）。
- **已有相关数据/行业背景**：优先做你最熟的领域，做得深比做得广更容易得高分。

## 达标最低要求（对照大赛硬性准入）

1. 是可运行的应用（Web/App/小程序/桌面均可），不接受纯脚本、命令行、Notebook。
2. 已部署，有公网可访问 URL 或安装包。
3. 后端真的通过 Server API 调了 InfiniSynapse（后台可查调用日志）。
