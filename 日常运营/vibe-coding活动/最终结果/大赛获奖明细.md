# InfiniSynapse × CSDN Vibe Coding 最终获奖名单

2 一等奖 + 4 二等奖 + 6 三等奖 + 50 优秀奖，共 **62** 件。截图来自 `vibe-coding-award-report/images/`。日期 2026-08-21。

一二三等奖品类互不重复。优秀奖品类允许重复。

## 评级怎么打

综合分 = 场景价值 × 40% + 技术完成度 × 35% + 创新性 × 25%。

| 综合评级 | 分数区间 | 含义 |
| :---: | --- | --- |
| S | ≥ 8.50 | 场景、完成度、创新都到头部，可当标杆 |
| A | 7.50–8.49 | 主路径成立，至少两项明显强 |
| B | 6.50–7.49 | 能用，但完成度或差异化不够拉开 |
| C | 5.50–6.49 | 方向对，材料或产品深度偏弱 |
| D | < 5.50 | 信息披露不足，或还停在概念 / demo |
