### 一句话定位（给博主理解用）

> **InfiniSynapse 不是「上传 CSV 聊天的 AI」，而是能直连企业数据库、跑完一整条分析链路、并把 SQL 和证据链一起交出来的 Data Agent。**

### 三句话卖点（内部对齐，对外表达请口语化）

1. **连真库**：MySQL、PostgreSQL、Supabase、Snowflake、ClickHouse 等可在同一任务里协同分析，不用先导 Excel。
2. **给证据**：不只给图表——返回 SQL、源表、过滤条件、指标口径和逐步执行明细，**每一步能点开复核**。
3. **能沉淀**：重要分析可存进记忆库，下次同类问题自动召回口径，不用从头教 AI。

## 二、绝对红线（必读）

### 1. 画面 / 截图真实性

| 要求 | 说明 |
|---|---|
| **必须真实使用** | 笔记中的产品界面须来自博主**本人账号**在 InfiniSynapse 内的真实操作；可录屏截帧，**严禁**套模板假 UI、纯 AI 生成界面、盗用他人录屏 |
| **必须露关键证据** | 至少 **1 张**能体现「不是黑盒聊天」——例如：**执行步骤列表**、**点开后可见的 SQL / 数据表**、或**任务完成后的结果校验** |
| **禁止只拍首页** | 封面 / 前 2 图不能只有登录页或空对话；要能看出「问了什么问题 → 得到了什么过程 / 结果」 |
| **数据脱敏** | 生产库截图须打码：公司名、客户名、手机号、API Key、连接串、内网地址、未公开财务数字 |
| **案例库优先** | 无自有数据库的博主，可向运营索取 **Demo 任务分享链 / 官方示例录屏素材**，并在文案中注明「示例任务」 |

**推荐截图清单（≥4 张有效产品图）：**

1. 提问区：业务问题 + 已选数据源（或连接成功状态）
2. 执行步骤列表：多步分析过程（不是只有一行回复）
3. 点开某步后的 **SQL + 数据预览**（或最大化明细面板）
4. 最终结果表 / 图表 + 「任务完成」或校验信息
5. （可选）记忆库保存 / 下次召回对比

## 三、创作方向（按场景选择）

博主**任选 1 个主方向**，也可在 1 篇内组合，但须有一个清晰主线。**选定后告知运营，便于分配专属链接与素材包。**

### 方向 A · 打工人效率（推荐 · 流量广）

**适合**：在职分析师、运营、财务、PM  
**叙事钩子**：「还在导出 Excel / 写 SQL 拉到半夜？」  
**体验路径建议**：

1. 连接一个数据源（或上传 CSV / 用官方 Demo）
2. 用自然语言问一个**真实业务问题**（如：上周各渠道转化率、某品类 GMV 环比、活动 ROI）
3. 展示 Agent **自己拆步骤、跑查询**，而不是一句话糊弄
4. 强调：**我敢点开 SQL 看**，不是盲信 AI

**可参考知识库案例**：`日常运营/记忆功能case-财务销售口径差异/` · Supabase 连接文

---

### 方向 B · 直连数据库 / 云仓库（推荐 · 专业向）

**适合**：数据工程师、DE、用 Snowflake / Supabase / Postgres 的开发者  
**叙事钩子**：「ChatGPT 只能聊 CSV，这个能直接连我的库」  
**体验路径建议**：

1. 展示数据源管理 / 连接成功界面（连接串打码）
2. 跨表 / 跨源问题（如订单 + 用户 + 埋点）
3. 突出 **多源同一任务** + **SQL 可追溯**

**可参考知识库案例**：`SEO/Blog/ai-analyst-real-data-supabase/` · Snowflake 实战 PDF 系列

---

### 方向 C · 记忆库 / 口径沉淀（差异化 · 适合深度博主）

**适合**：做过 recurring 报表、被「同一指标不同口径」折磨过的人  
**叙事钩子**：「同一句话，第二次问快很多，而且口径一致」  
**体验路径建议**：

1. 第一次：完整跑通分析，存进记忆库
2. 新会话：同一问题再问，展示 Agent **自动召回规则 / 双口径并列**
3. 对比「没记忆时 AI 瞎猜口径」的痛点

**可参考知识库案例**：`日常运营/记忆功能case-财务销售口径差异/`

---

### 方向 D · 对比 / 选型（商业意图高 · 需运营审核）

**适合**：常发 AI 工具测评、Julius / ChatGPT / Tableau 受众  
**叙事钩子**：「我试了 N 个 AI 数据分析工具，这个适合 XX 场景」  
**要求**：

- 对比必须基于**真实同题测试**，不能云评测
- 结论要留余地：「适合谁 / 不适合谁」
- 竞品名可提，**不贬低**，引用运营提供的对比 Blog 链接即可

**可参考知识库**：`SEO/Blog/pillar3-ai-analyst-tools/`（vs ChatGPT / Julius / Tableau 等）

---

### 方向 E · 学生 / 转行 Portfolio（长尾）

**适合**：准数据分析师、Bootcamp 学员、做课设的大学生  
**叙事钩子**：「做数据分析项目不用只会贴 Jupyter 截图了」  
**体验路径建议**：

1. 用公开数据集或课程 SQL 库完成一个小分析
2. 展示 **可交付的过程证据**（SQL + 结果），而不只是最终图
3. 引导：项目作品集里多一个「Agent 协作分析」维度

---

### 方向 F · 金融 / 合规场景（高信任 · 仅官方素材或已授权 Demo）

**适合**：金融科技、量化、合规向博主（需运营预审）  
**叙事钩子**：「收盘前 XX 分钟，AI 跑的合规扫描能复核吗？」  
**要求**：**必须使用运营提供的分享任务链或录屏素材**，禁止自行编造交易数据

**可参考知识库案例**：`日常运营/Fable5-NYSE合规监测case/视频脚本.md`

## 五、常见问题 Q&A

**Q1：我没有公司数据库，能发吗？**  
可以。向运营要 **Demo 分享任务链接** 或 **脱敏录屏素材**；文案注明「示例任务 / 公开数据集」，不要冒充生产环境。

**Q2：和 ChatGPT / Julius / Copilot 有什么区别？**  
一句话：**InfiniSynapse 是 Data Agent，目标是把「业务问题 → 可验证的分析结果」跑完，并留下 SQL 和步骤证据**；不是通用聊天或单文件上传工具。具体对比可参考运营发的 Blog 链接，勿自行编造竞品缺陷。

**Q3：会不会瞎编数据？**  
产品设计上强调 **执行明细可点开、SQL 可复核**；博主应展示这一特性，而不是只晒最终数字。对外表述用「我会核对 SQL / 样本」，不用「100% 准确」。

**Q4：必须录视频吗？**  
不必须。图文 ≥5 张即可；若发视频，60–90 秒为宜，**执行步骤段可加速，SQL / 结果表段必须正常速度**（参考 Fable5 录屏 Brief）。

**Q5：能提到价格 / 免费吗？**  
以运营当时口径为准；默认写「官网有免费体验额度 / 可注册试用」，**不承诺永久免费、不写具体未公布价格**。

**Q6：可以用官方截图吗？**  
可用运营 **素材包** 中的官方截图作补充，但 **至少 50% 须为博主账号内真实操作**（或明确标注「官方示例」）。

**Q7：发 Non-报备 还是报备？**  
按小红书当时规则及运营约定执行；本 Brief 默认 **非报备真实分享** 口径，**不勾选未实际存在的商业合作**。

**Q8：链接放哪里？**  
优先：**评论区置顶 + 个人简介**；正文末尾可放一次。使用运营提供的 `utm_source=kol_{昵称}` 专属链，便于统计。
