# GPT 5.6 Sol 演示包 · 经营异常诊断

> 场景：虚构 DTC「星澜优选」近 7 周渠道经营周报  
> 用法：上传 `demo-weekly-ops.csv` → 模型选 **GPT 5.6 Sol** → 粘贴下方 Prompt

---

## 演示步骤（约 2 分钟）

1. 新建任务，上传 `demo-weekly-ops.csv`
2. 选择模型 **GPT 5.6 Sol**
3. 粘贴「主 Prompt」发送
4. 截图用：**Top 3 异常 + 下周 3 条动作**（正文结论区即可）

---

## 主 Prompt（直接粘贴）

```text
你是星澜优选的经营分析 Data Agent。附件是近 7 周各渠道周度经营数据（week_start 为当周周一）。

字段说明：
- gmv_cny：成交额（元）
- orders：订单数
- refund_orders：退货订单数
- ad_spend_cny：广告花费（元）；自然流量为 0
- uv：访客数
- new_users：新客数

请完成：
1) 先计算每行的退货率 = refund_orders / orders，以及付费渠道 ROI = gmv_cny / ad_spend_cny（ad_spend 为 0 则跳过）。
2) 以「最近一周 week_start=2026-07-06」对比「此前 6 周均值」，找出最值得经营层关注的 Top 3 异常；每个异常必须包含：渠道、指标、本周值 vs 历史均值、变化幅度、一句话业务解释。
3) 基于这 3 个异常，给出「下周可执行」的 3 条动作建议（每条写清：负责人角色、具体动作、成功标准）。
4) 最后用一张 Markdown 表汇总 Top 3（列：异常、渠道、关键指标、本周、历史均值、变化、优先级）。

要求：所有数字从附件计算得出，禁止编造未出现的渠道或周次；不确定处明确标注「数据不足以判断」。
```

---

## 备用短 Prompt（时间紧时用）

```text
基于附件周度经营数据：对比 week_start=2026-07-06 与前 6 周，找出 Top 3 异常（含数字对比），并给出下周 3 条可执行动作。退货率=refund_orders/orders；付费 ROI=gmv/ad_spend。只依据附件计算，不要编造。
```

## 数据里预埋的 3 个异常（演示者对照，勿发给观众）

| 优先级 | 渠道 | 异常 | 大致信号 |
| --- | --- | --- | --- |
| P0 | 搜索广告 | 退货率飙升 | 本周约 **21.5%**，历史约 **4%** |
| P0 | 信息流 | 投放加码但产出变差 | 花费约 **17.8 万**（历史约 9.5 万），GMV/ROI 明显走弱 |
| P1 | 直播 | GMV 断崖 | 本周约 **19.8 万**，历史约 **60 万+** |

自然流量本周基本正常，可作为对照组。

## 字段一览

| 字段 | 含义 |
| --- | --- |
| `week_start` | 周起始日（周一） |
| `channel` | 搜索广告 / 信息流 / 直播 / 自然流量 |
| `gmv_cny` | 成交额（元） |
| `orders` | 订单数 |
| `refund_orders` | 退货订单数 |
| `ad_spend_cny` | 广告花费（元） |
| `uv` | 访客数 |
| `new_users` | 新客数 |

文件：同目录 `demo-weekly-ops.csv`（28 行 = 7 周 × 4 渠道）
