# 中文文章标点规则（写 InfiniSynapse 公众号 / 外部文章用）

写 InfiniSynapse 相关的中文外部文章（公众号、知乎、推文、博客）时使用此规则。**外部传播口径上，中英文标点混排会显得不专业**，本文档把"哪些转中文、哪些保留英文"一次性定死。

---

## 1. 一句话原则

**正文里的语义标点全部用中文全角；技术性字面量里的标点全部保留英文半角。**

"语义标点"=表达停顿、语气、引用、并列；"技术字面量"=URL/数字/时间/版本号/文件名/代码。

---

## 2. 必须转中文的符号

| 英文半角 | 中文全角 | 例子 |
|---|---|---|
| `,` | `，` | 那是个普通的周三上午，会议刚开了二十分钟 |
| `.` | `。` | 我下意识翻过来瞟一眼锁屏。 |
| `:` | `：` | 它给的最终结论是这么写的：xxx |
| `;` | `；` | 一段一段做；段段交差 |
| `?` | `？` | 这是它自己想出来要看的吗？ |
| `!` | `！` | 终于跑完了！ |
| `"..."` | `"..."` | 领导回了句"好的" |
| `'...'` | `'...'` | 它说'快、干净' |
| `(...)` | `（...）` | 看着体面（月底吃土） |
| 顿号场景 `/` | `、` 或 `／` | 年龄、性别、收入；并列字段用 `／`：年龄／性别／收入 |

---

## 3. 必须保留英文的场景（千万别转）

| 类别 | 例子 | 为什么不转 |
|---|---|---|
| **数字小数点** | `41.71%`、`833.1 KB`、`v1.2.3` | 这是数学/版本号 |
| **数字千分号** | `7,444 行`、`1,200,000` | 千分号必须半角 |
| **时间冒号** | `10:22`、`11:00 AM` | 时间格式 |
| **数值/范围连字符** | `10k-15k`、`35-44 岁` | 范围符号 |
| **域名/URL** | `app.infinisynapse.cn`、`https://...` | 域名/链接 |
| **文件名扩展** | `.xlsx`、`.md`、`.png` | 文件后缀 |
| **代码/命令** | `` `app.infinisynapse.cn` ``、`SELECT * FROM` | 代码字面量 |
| **markdown 语法** | `1. ` `2. ` 列表、`![](url)`、`[](link)` | 解析需要 |
| **英文单词内的撇号** | `don't`、`it's` | 英文语法 |
| **emoji + 文字间空格** | `📎 月光族数据集.xlsx` | 视觉留白 |

## 4. 排版细节（同样重要）

### 4.1 中文全角标点后**不要加空格**

❌ `那一刻， 我楞了一下。 然后切到龙虾。`
✅ `那一刻，我楞了一下。然后切到龙虾。`

中文全角标点本身已经包含右侧的视觉空白，再加空格就变成"双倍空格"，看起来很松散。

### 4.2 中英文之间**保留一个空格**（盘古之白）

✅ `我用 InfiniSynapse 跑了一下分析`
✅ `833KB 的 Excel`
✅ `跑完整套用了 3 分钟`

❌ `我用InfiniSynapse跑了一下分析`（挤）
❌ `我 用 InfiniSynapse 跑了一下 分析`（中文之间也加空格，错）

规则：**中文 ↔ 英文/数字 之间加一个半角空格；中文 ↔ 中文之间不加；英文 ↔ 英文之间加正常空格。**

### 4.3 破折号用 `——`（两个全角横）

✅ `屏幕朝下——这是我跟自己定的规矩`
❌ `屏幕朝下--这是我跟自己定的规矩`
❌ `屏幕朝下—这是我跟自己定的规矩`（只用一个）

破折号前后**不要加空格**（不像英文 em-dash 那样会留白）。

### 4.4 省略号用 `……`（两个全角点点）

✅ `我想了想……还是先发"好的"`
❌ `我想了想... 还是先发"好的"`

### 4.5 引号优先用直引号 `""` `''`，不强制弯引号

公众号 / 知乎都对 `""` `''` 直引号渲染良好。**只在使用纯文本平台（无富文本渲染）时考虑用弯引号 `""` `''`**，避免某些字体下直引号被吞或显示成竖线。

## 5. 自动化转换的踩坑（如果用脚本批量转）

写过的脚本在 `infinisynapse-app-skill` 下没保留——血泪教训：

### 5.1 不要用 `\s+` 配合 lookahead 删空格

```python
# ❌ 这一行会把换行也吃掉，整篇文章变成一行
re.sub(r'([，。：；？！])\s+(?=\S)', r'\1', text)
```

`\s` 在 Python re 默认包含 `\n`。**用 `[ \t]+`** 显式只匹配空格 / tab：

```python
# ✅ 只删水平空白
re.sub(r'([，。：；？！])[ \t]+(?=\S)', r'\1', text)
```

### 5.2 列表序号 `1. ` 会被误转

`1.` 后面是空格，看起来像句号 + 空格的模式。脚本里要加例外：

```python
# 在 "." → "。" 转换里加一条 guard：
# 行首的 "<digit>. " 不转
if re.match(r'^\s*\d+\. ', current_line_so_far):
    pass  # 保留半角点
```

### 5.3 URL 内的 `:` 别转

`https://...` 里的冒号不能动。脚本里把整个 URL 视作"保护区域"：

```python
url_re = re.compile(r'https?://[^\s)]+')
# 先把 URL 替换成占位符 → 转标点 → 还原 URL
```

注意 `\S` 包含 `:` 所以匹配会延伸太远，用 `[^\s)]` 排除右括号才能在 markdown link `[..](url)` 里准确停在 `)` 之前。

### 5.4 markdown link 内的 `:` `,` `.` 全部不转

```python
md_link_re = re.compile(r'\]\(([^)]*)\)')
# 同样：先替占位 → 转 → 还原
```

### 5.5 代码块要整段跳过

```python
in_code = False
for line in lines:
    if line.lstrip().startswith('```'):
        in_code = not in_code
        out.append(line); continue
    if in_code:
        out.append(line); continue
    out.append(convert_line(line))
```

### 5.6 行内代码也要跳过

```python
# `xxx` 之间的内容不转
# 简单做法：split 成奇偶段，奇数段（在 ` ` 内）不转
parts = re.split(r'(`[^`]*`)', line)
for i, p in enumerate(parts):
    if i % 2 == 0:
        parts[i] = convert_punct(p)
return ''.join(parts)
```

## 6. 推荐工作流（写完文章 → 检查标点）

1. **写作时直接打中文标点**（macOS 中文输入法默认就是全角；不用 shift+, 而是逗号键直接出 `，`）
2. **写完后人眼扫一遍** 这几个最容易漏的位置：
   - 标题行尾常被遗忘 (`## 标题: xxx` → `## 标题：xxx`)
   - 列表项行尾的句号 (`- xxx.` → `- xxx。`)
   - 引用块 `> "..."` 内的标点
3. **批量检查命令**（在文章目录下跑）：

```bash
# 找出所有可疑的英文标点（数字/代码上下文除外）
rg -n '[\u4e00-\u9fff][,.:;?!]' article.md
# 这条会输出所有"中文字 + 英文标点"的位置 → 几乎全是要改的
```

4. **批量转换的最后兜底**：实在要写脚本，按 §5 的避坑清单写。

## 8. 与本 skill 其它部分的关系

- 写文章产物在 `产品/InfiniSynapse/文章/<topic>/article.md` 或 `外部合作/外部文章/<date>-<slug>/article.md`
- 任何外发文档（公众号 / 知乎 / Reddit 中文 / 微信社群文案）都按本规则
- **代码注释 / 命令行 / 技术文档（如 SKILL.md 本身）不强制**，技术文档保留半角更利于 grep 和 diff
- Reddit / X / 英文外发的内容**不适用**本规则（按英文标点习惯）
